## Decisions and constraints

- PO chose isolated main-based staffing PR followed by cumulative RC.3.1 reconciliation. Warn below minimum; allow travel only after explicit GM acknowledgement. All eligible NPC crew paid when wages enabled, PCs unpaid, hired hands paid. Allocate crew to individual operating units, estimate only selected units.
- World defaults → Party owned resource or Map Marker hire override → Journey-local draft → explicit GM approval → immutable Journal snapshot. No write on read, no native Group/Actor/currency mutation, no auto payment or boarding; leave-behind is Journey participation only. GM authority beyond UI. Respect native movement and verified recovery anchors; conflicting evidence halts.
- Preserve explicit zero rates and missing vs empty crew rosters. Default warship minimum/optimal/excellent/full 15/30/45/60; other crewed profiles use ceiling 25/50/75% of reference full. Thresholds advisory, not automatic speed or movement penalties. Named crew occupy crew positions, not seats; one named member per unit assignment, unique across units/resources.
- Prefill previously unpriced applicable hire rates using editable reference 1% of purchase GP per operating day; retain existing rates, do not enable hire/stock. Walking free. Hired services use inherited tier-specific rate/schedule overrides, existing day/trip/mile and unit/passenger bases, standard/overtime/continuous capability. Minimum standard, optimal/excellent eligible overtime (up to 16 h), full eligible continuous (24 h), with valid overrides. No new independent vehicle clocks in a mixed convoy. Preserve existing continuous billing, livestock fare policy, rounding per method then sum, crew-included fare policy and legacy approvals. Owned continuous standard-day billing retained.
- Design references (read-only for implementation): [FigJam workflow](https://www.figma.com/board/GeDq3GNuqENTXUz71H5y4N) and [MagicPath prototype](https://designs.magicpath.ai/v1/sweetly-rain-3285) (project 476000758899281920, component 476002770026115072, revision 476002770026115073). Prototype is illustrative; native ApplicationV2/DialogV2/DOM/CSS, no React or other new runtime dependency. Product Design, MagicPath, Figma, Context7, Graphify, Superpowers, Ponytail and Agent Skills support engineering; use current source and verify APIs, not outdated graph or prototype as authority.
