## Stop / rollback

Stop immediately if movement replays, checkpoint/Journal evidence conflicts, a stale approval is silently repriced, access is exposed, or a native document changes unexpectedly. Preserve logs and the backup; do not clear Journey flags or manually teleport to bypass guards.

For rollback, stop the test, exit the World, restore the previous module files or reinstall the main manifest (Foundry may require manual downgrade/reinstall), and restore the matching pre-test World backup before using the older module. Stable manifest: https://raw.githubusercontent.com/i-am-rayo/fvtt-atlas-navigation/refs/heads/main/module.json. Do not assume older code can safely read every newly saved staffing record. Keep the failed test World's evidence separately. No production release until explicit PO acceptance.
